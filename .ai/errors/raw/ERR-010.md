### ERR-010: 重构 __init__ 时剩余初始化行被吸收进新方法体

- **症状**: 重构 `BleakOtaClient.__init__`（加 event_cb 字段）后，CLI dry-run 报 `AttributeError: 'BleakOtaClient' object has no attribute '_pending'`，Start 握手失败；notify 回调亦炸
- **根因**:
  1. 直接原因：Edit 的 old_string 只覆盖到 `self.verbose = verbose`，构造函数尾部原有的 `_pending`/`mtu_size`/`last_acked_sector`/`stats` 初始化行落在了新插入的 `emit()` 方法体内——属性只在 `emit()` 被调用时才初始化，构造后即为缺失
  2. 深层原因：old_string 锚点选在构造函数**中部**而非方法边界，Edit 工具在锚点与下一方法之间的"剩余文本"无感知；且回归测试放在了重构完成后一次性跑，错误暴露晚了一步
- **修复**: 把被吸收的初始化行移回 `__init__`；`emit()` 只保留通知逻辑。随后补齐完整回归矩阵（--help / scan 真机 / dry-run 真机 / 协议自测）
- **规律提炼**:
  1. 对既有方法做 Edit 时，old_string 锚点必须包含**完整方法边界**（从 def 到方法末行），绝不在方法体中部锚定——否则锚点之后的原方法体行会被新内容"吸走"
  2. 改构造函数 = 改对象生命周期，回归必须在改动后立即跑最小实例化路径（构造 + 首个用到各属性的方法），不能攒批验证
- **二次提炼接口**: META-007-BUILD（构造函数/初始化路径修改后必须立即实例化冒烟；锚定方法中部编辑必查方法尾部完整性）
- **首次出现**: 2026-09-02
- **复现次数**: 1

### ERR-002: EIM 激活脚本从脚本文件 source 时静默退出整个 shell

- **症状**: wslbuild.sh 里 `source /root/.espressif/tools/activate_idf_v6.0.2.sh` 后脚本静默终止（无任何输出，EXIT=1），且 -x 跟踪只显示到 source 行
- **根因**: EIM 生成的激活脚本用 `is_sourced()` 检测 `$0`：交互 shell 下 `$0=bash` 判定为 sourced；但**从脚本文件 source 时 `$0` 是脚本文件名** → 判定为"被执行" → 走到 `echo "This script should be sourced"` + `exit 1`，由于处于同一 shell 进程，直接退出调用方脚本
- **修复**: 不 source，改 `eval "$(activate_idf_v6.0.2.sh -e)"` —— `-e` 模式输出 KEY=VALUE 环境变量列表，eval 后可用 $IDF_PATH/$IDF_PYTHON_ENV_PATH，再显式拼 `python $IDF_PATH/tools/idf.py`
- **规律提炼**: 第三方环境激活脚本不可盲目 source，先看它的 sourced/检测逻辑；EIM 系列一律用 `-e` + eval 模式
- **二次提炼接口**: META 规则 —— [BUILD] EIM activate 脚本只允许 `eval "$(script -e)"` 方式注入环境，禁止 source

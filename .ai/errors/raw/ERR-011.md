### ERR-011: GUI worker 线程读取 tkinter Variable 崩溃

- **症状**: GUI 烧录启动即失败，worker 报 `RuntimeError: main thread is not in main loop`，传输 0 sector
- **根因**: `on_start` 投递给 worker 的闭包里调用 `self.dry_var.get()`。tkinter Variable 绑定主线程解释器的 Tcl 解释器，跨线程调用其 `_tk` 句柄直接抛 RuntimeError——这比"访问 UI 控件要小心"更严格：**不是竞态问题而是根本不允许**
- **修复**: 在 GUI 线程（on_start 内）先把 `dry_var.get()`、`dev["address"]` 等取成普通 Python 值，闭包只捕获普通值
- **规律提炼**: tkinter Variable 与控件同属"仅主线程可触碰"资产。跨线程投递任务时，参数必须在投递方（主线程）就地解包为纯数据，worker 闭包不得引用任何 tkinter 对象（含 Variable、控件方法）
- **二次提炼接口**: 任何"主线程 UI + worker 线程"架构中，worker 任务签名应为 `(worker_obj, *纯数据参数)`；回调桥接 UI 更新必须经队列轮询或 after()，反向传参必须值快照。 tkinter 检查项：grep worker 闭包体内是否有 `.get()`/`.cget()`/控件方法调用
- **首次出现**: 2026-09-02
- **复现次数**: 1

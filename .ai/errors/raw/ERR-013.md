### ERR-013: 会话重试路径三缺陷——armed 清除致 lazy-open 永不触发、ringbuf 残留错位写入、Stop 与收尾竞速误杀会话

- **症状**: PR-1 真机回归 B（传输 ~30% 杀 host 进程 → 重连重试）三个层面暴露：
  1. 设备侧串口显示 `old session invalidated by ble (Start)` 后**再无第二次 `session open`**——重试传输 161 sectors 全部被组件 ACK 但数据被 transport 丢弃，设备不重启；
  2. 重试成功轮次中，重试 Start 后紧接 `STALE write dropped (epoch old=1)`，说明 ringbuf 残留的旧会话 chunk 正被送往（或阻塞着）写路径；
  3. 初版回归 A（happy path）：161 sectors 传完、设备实际重启成功（串口 finish ok → activated → PENDING_VERIFY confirmed），但 host 侧 Stop ACK 正常返回即判 FAIL——"Stop ACK 正常返回=未重启"的反转判据在真实收尾时序下不成立。
- **根因**（连问三层）:
  - ①lazy-open 永不触发：泵任务在 STALE/write-fail 处理路径里顺手 `s_armed=false`——armed 的所有权被两个上下文（会话回调与泵任务）同时持有。重试 Start 置 armed=true 后，泵任务处理 ringbuf 里残留的旧会话 chunk（断连瞬间在途的 1-2 个）→ STALE → 又把 armed 清掉 → 后续新会话 chunk 全走"未 armed 丢弃"分支。根因是**一个 volatile 标志被授予两个写入者，且两者对"会话该不该开"的认知相反**。
  - ②错位写入窗口：初版 armed=true 后 ringbuf 里的 straggler（旧会话在途 chunk）会在 lazy-open 后被当作新会话第一个 chunk 写入 offset 0——P0-1 错位链的变体（epoch 拦住了旧 epoch 写入，却拦不住"旧数据进新会话"）。
  - ③Stop 判据失效：esp_ota_end（镜像 hash 校验数百 ms）+ set_boot 在最后 sector ACK 之后执行，Stop 命令的空口往返（~10ms）能抢在 esp_restart 前被组件正常 ACK——"Stop ACK 正常返回=设备没重启"只在 esp_ota_end 同步挡住任务时成立，而新收尾链恰好留了窗口。
- **修复**:
  - armed 所有权收敛：只有 vendor 会话回调写 armed（START 置位 / STOP+DISCONNECT 清零），泵任务**任何路径不再清 armed**；
  - START 回调非阻塞排空 ringbuf（timeout=0 循环取 item 丢弃）——旧会话 straggler 全部作废，新会话 sector 0 最早在 Start ACK 空口往返 ~100ms 后入队，排空窗口充裕且确定性成立（不靠竞速）；
  - 泵任务 receive 改 100ms 超时轮询：数据路径不检查 armed（保收尾），超时路径检查 armed（armed=false 且有会话 → `session abort by ble` 收敛）；
  - open 失败 latch `s_open_blocked` 门控数据源（size=0/超分区后组件残余数据不入队），START 清除；
  - host 判定反转修正为"广播空窗观测"（wait_reboot_with_gap）：真实 esp_restart 必然使广播消失 1.5-2.5s（controller 重建），9s 窗口内出现空窗=重启成功；持续可见=未重启=FAIL。Stop ACK 降级为信息性事件（P2-14 顺带：Stop 专用 3s 短超时）。
- **规律提炼**: 会话/状态标志必须单写者（所有权归"事件源头"上下文），泵/消费者只读；消费者路径上的错误处理禁止顺手改生产者协议状态。异步流的重定向（旧会话→新会话）必须有显式的"排空旧数据"步骤，靠时序假设（"新数据会晚于标志置位到达"）而无排空动作=竞速窗口。上位机的成功判定不能用单一协议事件（Stop ACK）推断物理行为（重启），要观测物理层不可伪造的信号（广播空窗）。
- **二次提炼接口**: META-010-CONCURRENCY（会话标志单写者 + 流重定向必排空）；上位机判定设计见 META-010 的检查项 3。
- **首次出现**: 2026-09-03（PR-1 真机回归 B/A）
- **复现次数**: 1（回归 B 两轮复现同一缺陷面：初版 3 处病灶；修复后 D/G 两轮全绿）
